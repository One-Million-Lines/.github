# One Million Lines Project


**OneMillionLines** is an open, community-driven experiment:  
a single repository that groups multiple real projects, tools, and experiments — all supported by people who believe in building in public.

The idea is simple:
> support builders → fund real work → ship useful things.

No hype. No courses. Just projects that exist, evolve, and stay open.

---

## What is OneMillionLines?

OneMillionLines is a **meta-project** that hosts and connects multiple independent sub-projects.

Each sub-project:
- Solves a real problem
- Is built in public
- Can be supported directly
- Keeps shipping improvements over time

Think of it as a **workshop**, not a product.

---

## Projects

https://onemillionlines.com/projects


Each project contains:
- Its own README
- Clear scope and goals
- Current status (idea / WIP / shipped)
- How to use it
- How to support it

You can support one project, multiple projects, or the whole initiative.

---

## Why This Exists

Most side projects die because:
- There’s no early feedback
- No financial support
- No incentive to keep polishing

OneMillionLines flips that:
- Support comes early
- Builders stay motivated
- Supporters shape what gets built next

You’re not buying a promise — you’re backing active work.

---

## What You Get by Supporting

Depending on the project, supporters may get:

- Early access to features
- Direct influence on roadmap decisions
- Lifetime usage for that project
- Private updates or changelogs
- Your name listed as a supporter (optional)
- Access to experiments that won’t be public

Exact perks are defined per project — no vague bundles.

---

## What You *Don’t* Get

- No generic “info product”
- No recycled content
- No locked knowledge behind upsells
- No fake scarcity

Everything is transparent.
